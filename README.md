# SOLUCIONES JURÍDICAS SJ - Landing Page

Landing Page profesional para el bufete jurídico **SOLUCIONES JURÍDICAS SJ** con navegación horizontal y diseño en tema oscuro.

## 📋 Características

- ✅ **Navegación Horizontal**: Transiciones suaves entre secciones en el eje X
- ✅ **Tema Oscuro Profesional**: Paleta de colores sobria y elegante
- ✅ **Mobile-First**: Diseño completamente responsive
- ✅ **Gestión de Estado**: Pinia para manejo centralizado del state
- ✅ **Swipe Gestures**: Navegación táctil en dispositivos móviles
- ✅ **Navegación con Teclado**: Flechas para desktop
- ✅ **Formulario de Contacto**: Validación en tiempo real
- ✅ **Animaciones Suaves**: Transiciones profesionales

## 🚀 Tecnologías

- **Vue 3** (Composition API)
- **Vite** (Build tool)
- **Pinia** (State management)
- **Vue Router** (Routing)
- **SCSS** (Estilos)
- **Bootstrap Icons** (Iconografía)

## 📂 Estructura del Proyecto

```
src/
├── components/
│   ├── common/          # IconBox, SocialLinks
│   ├── layout/          # AppHeader, AppFooter, NavigationDots
│   ├── sections/        # HeroSection, AboutSection, etc.
│   └── ui/              # CTAButton, ServiceCard, ContactForm, etc.
├── composables/         # useSwipe, useKeyboardNav, useScrollSnap
├── router/              # Configuración de Vue Router
├── stores/              # ui, navigation, contact, content (Pinia)
├── styles/              # SCSS modular
├── utils/               # constants, validators, animations
└── views/               # HomeView
```

## 🎨 Paleta de Colores

- **Fondo**: `#0a0a0a` - `#1a1a1a`
- **Texto**: `#ffffff` - `#e0e0e0`
- **Acentos**: `#dc3545` (Rojo)

## 📦 Instalación y Uso

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build para producción
npm run build

# Preview
npm run preview
```
